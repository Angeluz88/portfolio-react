## 📌 About the Project

This is my personal portfolio website built to showcase my work as a **FullStack Developer**.

The application is developed as a **Single Page Application (SPA)** using React, focused on performance, scalability, and clean UI/UX design.

It provides an interactive experience where users can explore my projects, access live demos, and understand my technical skills.

---

## ✨ Key Features

- 📱 Fully responsive design (mobile-first)
- 🔄 Dynamic navigation with React Router
- ♻️ Reusable component architecture
- 🎨 Modern UI with animations and transitions
- 📂 Project showcase with live demos and repositories
- ⚡ Optimized performance and fast loading

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Angeluz88/portfolio-react.git
```

### 2. Navigate to the project

```bash
cd portfolio-react
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the project

```bash
npm run dev
```
